# Chapter 5: Conclusion & Future Work

## 5.1 Thesis Summary
This thesis has successfully engineered and validated an automated, line-gate filtering SAST compilation framework designed to isolate the security profiles of AI-generated and human-authored code additions. By pairing CodeQL semantic graph taint analysis with exact git diff coordinates, this study eliminated legacy technical debt pollution from security evaluation logs, solving a major methodological flaw in current software engineering literature. 

The empirical evaluation of 2,000 pull requests across the AIDev dataset confirms that autonomous AI agents introduce a substantial security regression when compared to human baselines, generating a **121.5% higher defect density per line** and an **87.5% increase in defective submissions**. While both groups share a taxonomical convergence around core validation flaws like `CWE-020` and `CWE-079`, agents exhibit a unique vulnerability profile driven by algorithmic complexity and string processing errors like `CWE-1333`. Finally, this work exposed the behavioral mechanics of the **Risk Acceptance Paradox**, mathematically proving that while maintainers are more skeptical of AI code, human-authored flaws are dismissed and merged into production at a significantly higher rate (**75.0% vs 46.67%**) due to social trust heuristics.

## 5.2 Future Work
While this study provides a definitive empirical baseline for SE 3.0 agentic pull requests, several critical vectors remain open for future academic investigation:
1. **Dynamic Context-Aware Multi-Turn Remediation:** Future iterations should evaluate the security efficacy of integrating active feedback loops directly into the pipeline. Building on the insight that feeding raw SAST alert logs into conversational assistants yields superior code patches, the framework could be extended to programmatically block defective PRs and automatically reply with line-specific CodeQL remediation scripts to achieve autonomous self-healing repositories.
2. **Expansion to Compiled Languages and Polyglot Environments:** The current experimental scope was restricted primarily to interpreted script profiles (Python, JavaScript, TypeScript). Future research should expand the AST mapping and memory safety filters to compiled enterprise frameworks (e.g., Java, Go, Rust) to evaluate whether strict type-checking and memory safety parameters minimize or amplify agentic logic truncation errors.
3. **Deep Thematic Tracking of Maintainer Comments:** To further unpack the psychological mechanics behind the Risk Acceptance Paradox, future work should pair the quantitative JSON database metrics with natural language processing (NLP) and sentiment analysis of live pull request review conversations. Tracking the exact linguistic patterns that lead maintainers to dismiss a CodeQL alert will facilitate the design of objective, bias-free continuous integration screening dashboards.
